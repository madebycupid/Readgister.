# 📚 Readgister (2025)

An archived school library management system developed in 2025.

**Readgister** is a web-based library management system created by a group of second-year Bachelor of Science in Information Technology students, with the project primarily led by **Charlie Balsomo Jr.** It was developed as our final course project.

Built with **Python**, **Flask**, and a fully functional **MySQL** database, Readgister simplifies library management by helping students and librarians efficiently track, borrow, and manage books through an easy-to-use interface.
